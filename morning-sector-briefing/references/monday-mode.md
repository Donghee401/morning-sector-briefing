# 월요일 특수 모드

브리핑 대상: 금요일 국장 마감(15:30 KST) → 월요일 08:30 KST. MCP 호출 상한 64회.

- **전일(미장) = 지난 금요일** (토·일 날짜 입력 금지).
- 검색2c-A의 `date` = 지난 금요일.
- MCP-8은 평일과 동일 1회, 별도 확장 없음(국내 주말공백은 당일 최신 결과로 갈음 — 미국 주말이슈는 아래 추가 호출이 커버).
- **MCP-7 pubDate 완화**: 평일은 전일·당일 기사만, 월요일은 금·토·일·월 기사 포함(NaverSearch 응답의 pubDate로 판단).
- **금요일 국내 휴장 시**: krx-holidays-2026.md로 지난 금요일이 휴장이면, 직전 실제 거래일까지 pubDate 확장(예: 금 휴장·목 마지막 거래일이면 "목~월"). 미국 "전일(미장)"은 이 확장과 무관하게 실제 미국 마감일 그대로.
- **월요일 추가 호출** [1회]: `web_search_exa(query="미국 증시 주말 뉴스 관세 정책 시장", numResults=5)` → 토·일 미국 관련 기사 수집, MCP-7 후보 반영.
