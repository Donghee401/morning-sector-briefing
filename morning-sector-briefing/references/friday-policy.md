# 금요일 특수 모드 (weekly-policy-calendar 흡수)

MCP 호출 상한 66회. 프레이밍: "다음 주 국회 일정 미리보기". 월요일 배치 금지(weekly-action-review와 시간대 중복).

## 정책 검색 (STEP3 수집과 함께 실행)

**정책1** `NaverSearch-search_news(query="국회 본회의 상임위 법안 다음주 일정", sort="date", display=3)` [1회] → pubDate 5일 이내. D-7~D-14 처리예정 법안(반도체특별법/원전/방산수출/AI규제/에너지전환/의료기기바이오/우주개발) + 처리단계(상임위통과/본회의상정/통과확정) 메모.

**정책2** `NaverSearch-search_news(query="정부 정책 발표 예정 다음주 부처 계획", sort="date", display=3)` [1회] → pubDate 5일 이내. 부처 발표예정/예산배정확정/클러스터조성/규제완화/대통령순방 + 날짜·부처·요약.

**정책3** [조건부 1회, 정책1·2에서 강신호 시만] `web_search_exa(query="[핵심 법안/정책명] 수혜주 관련주", numResults=3)` → 가장 임박·구체적 이벤트 1개만. 결과 없으면 생략.

## 신호강도 (STEP4 점수표와 별개 분류 — 등급 기호와 혼동 방지 위해 다른 기호)

본회의통과확정/예산확정→🔥임박(즉각수혜) / 상임위통과·D-3이내→👀주시(선점기회) / 논의중·날짜불명확→💭참고.

## 섹터 연결 맵

반도체특별법·클러스터→반도체/HBM소부장(한미반도체·리노공업·이수페타시스 등) / 원전확대·SMR→원전기자재(두산에너빌리티·한전KPS·비에이치아이 등) / 방산수출·정상회담→방산(LIG넥스원·한화에어로스페이스·한국항공우주 등) / AI·데이터센터전력→전력인프라(LS일렉트릭·효성중공업·현대일렉트릭 등) / 우주개발진흥→우주(이노스페이스·쎄트렉아이·AP위성 등) / 바이오·의료기기허가완화→바이오 CDMO(삼성바이오로직스·루닛·뷰노 등) / 전기차·배터리보조금→2차전지소부장(에코프로비엠·포스코퓨처엠 등) / 조선발주·LNG→조선(HD현대중공업·삼성중공업·HSD엔진 등) / 사이버보안의무화→사이버보안(안랩·지니언스·이글루시큐리티 등)

## 원칙

- **제외**: 지역연고만·법안무관 단순테마·다음분기내 처리불가 장기이슈.
- **표기규칙**: "상임위통과"/"본회의상정"/"본회의통과" 정확 구분.
- **근거원칙**: 섹터맵은 예시일 뿐 — 그 주 실제 뉴스·공시 확인 종목만 카드에. 정책 신호강도만으로 자동 액션플랜 승격 없음(STEP4 갭 기준 별도 충족 필요).

## 출력 반영

- STEP5 ④D-7이벤트: 실적리스트 아래 "📋 다음주 정책 캘린더 미리보기" 카드 추가(메인표엔 실적만, 정책데이터는 카드에만 — 중복배치 금지. 경제지표 카드는 FMP-economics 플랜미지원으로 폐지됨).
