## 어떻게 작동하나

```
날짜·휴장일 확인 → 시장 데이터 수집(환율·금리·VIX·미국 섹터·국내 공시·뉴스)
→ 후보 종목 발굴 → 종목별 강화신호 15종(임원매매·재무·밸류에이션·기술지표·자사주·지분변동)
→ 갭 4종(시간·정보·수급·가격) 점수화 → 🔴최우선매수/🟢주목/🟡점검 등급 판정
→ HTML 브리핑 Gmail 저장 + 카카오톡 요약 전송 + 일일 로그 기록
```

- **MCP 호출 예산 하드캡**(평일 63회) — 폭주 방지
- **소스 장애 폴백 체인** — 데이터 소스가 죽어도 브리핑은 나감
- **펀더멘털 캐싱** — 분기 공시 데이터는 10거래일 재사용
- **결정론적 기술지표** — RSI/MACD/볼린저를 LLM 암산이 아닌 동봉 스크립트(`scripts/compute_ta.py`)로 계산
- **SEC 공식 내부자매매** — OpenInsider 커넥터로 미국 임원 자사주 매수 신호 (실데이터 검증 완료)

**개발 지식이 없어도 됩니다.** [Claude Code](https://claude.com/claude-code)를 설치하고 이 저장소를 클론한 뒤, **`SETUP-PROMPT.md`의 프롬프트를 통째로 복사해 Claude에게 붙여넣으세요.** Claude가 환경 점검부터 커넥터 연결, 개인화, 테스트 실행, 자동 스케줄 등록까지 단계별로 안내합니다.

### 미리 알아둘 것

- **바로 되는 것**: `.mcp.json`의 커넥터 2종(미국 내부자매매·한국 시세)은 API 키 없이 작동합니다.
- **직접 준비해야 하는 것**: 스킬이 참조하는 개인 데이터 파일(관심 섹터 가치사슬맵, 휴장일 표, HTML 템플릿)은 저장소에 포함돼 있지 않습니다 — 세팅 프롬프트가 함께 만들어 줍니다.
- **전체 기능에 필요한 것**: 뉴스 검색(네이버), 미국 시장 데이터(FMP), DART 공시(OpenDART), Gmail·카카오톡 전송 커넥터. 없는 커넥터는 스킬의 안전망이 자동 생략하므로 부분 구성으로도 돌아갑니다.
- **선택 업그레이드**: KRX 무료 계정(외국인/기관 수급 공식 수치), DART API 키 — `UPGRADE-PLAN.md` 참고.
